## A. Technical Roles & System Architecture

### Software Architect

* System architecture design based on *domain view* & interactive dependency mapping (`Understand-Anything`)
* Automated creation & updates of HTML/SVG-based system architecture diagrams (`architecture-diagram-generator`)
* Analysis of system boundaries, *bounded contexts*, and cloud scalability planning
* Establishing security standards, *security gate* criteria, and technical framework selection

### Lead Developer (Tech Lead)

* Translating business requirements into structured work instructions (*execution briefs*) for the team & AI agents
* Integration of *Contextual Commits* standards (`intent`, `decision`, `rejected`, `constraint`, `learned`) into git logs
* Breaking down large features into isolated, independent task units for parallel execution
* Conducting code quality audits (*code reviews*), evaluating regression severity, and bridging business with technology

### Front-End Developer

* Building user interfaces based on modular components and a consistent design system
* Translating interactive UI/UX specifications into clean, flexible, and accessible code
* Integrating UI state data flow with REST API / GraphQL server
* Aligning rendering performance, *Lighthouse scoring*, and visual asset optimization

### Back-End Developer

* Programming business logic, data transactions, and authentication/authorization management
* Managing database schemas, query optimization, and maintaining *caching* layers
* Integrating structured API interfaces and generating automated integration documentation
* Monitoring server-to-server data flow and handling capacity constraints (*rate limiting*)

## B. Project, Product Management & AI Strategy

### Product Manager (PM)

* Executing AI-native PM workflows (`superPM`) for PRD drafting, OKR alignment, and GTM strategy
* Executing structured 2-phase market research (*outline generation* & *deep investigation*) via agents (`Deep-Research-skills`)
* Product roadmap mapping and precise competitive market analysis
* Defining product success metrics (KPIs/North Star Metrics) and evaluating user satisfaction

### Product Owner (PO)

* Managing & prioritizing the *Product Backlog* based on business value
* Drafting detailed *User Story* descriptions complete with *Acceptance Criteria*
* Validating release functionality against actual business needs
* Facilitating *Sprint Planning* cycles and aligning technical details with the Tech Lead

### Project Manager & Agile Master

* Managing schedules, budget allocation, and cross-domain team workflow coordination
* Implementing Agile/Scrum frameworks and removing team operational bottlenecks
* Monitoring workload rhythm to prevent team member *burnout*
* Early identification of project delay risks and preparing mitigation plans

## C. AI & Agent Operations & Governance Specialists (AI & Agent Ops)

### Agentic Workflow Engineer / Skill Developer

* Mining repetitive workflow patterns from team interaction sessions into *Agent Skills* (`skill-miner`)
* Auditing, customizing, and personalizing *skills* according to local habits and directories (`skill-personalizer`)
* Generalizing and publishing internal *skills* to public or team repository directories (`skill-generalizer`)
* Maintaining an integrated *agent skills* catalog (`awesome-agent-skills`)

### Agent Governance & Quality Orchestrator

* Standardizing naming, markdown formatting, and *skill/plugin* version control (`cortex-ai-skills`)
* Security auditing of tool execution permissions (*tool permission check*) to prevent malicious execution bypasses
* Configuring directory isolation protocols for conflict-free multi-agent parallel execution (`agent-smith`)
* Monitoring *recursion depth* limits and token allocation constraints in automated workflows

## D. Testing, Security & Release Governance

### QA Engineer (Manual & Exploratory)

* Functional validation from the perspective of real user experience
* Designing edge cases and negative scenarios beyond automation reach
* Reporting business flow discrepancies and verifying bug fixes
* Evaluating interface usability (*usability testing*) prior to launch

### QA Automation Engineer

* Writing and maintaining automated test scripts based on TDD / BDD
* Integrating automated tests into the *CI/CD Pipeline* to verify every code change
* Executing automated regression testing on critical features
* Analyzing test coverage and reporting release reliability

### Security & Compliance Tester

* Identifying application security vulnerabilities through penetration testing
* Auditing AI agent tool permissions and checking for credential/sensitive data leakage risks
* Evaluating resilience against cyber attacks (OWASP Top 10, code injection, misconfiguration)
* Drafting security improvement recommendations and regulatory data compliance before release

## E. Design & User Research

### UX Designer

* Designing application user flows and structured information architecture
* Researching user behavior and creating User Journey Maps
* Creating wireframes and interactive prototypes
* Validating navigation ease and application workflow efficiency

### UI Designer

* Designing visual design systems (typography, colors, components, and iconography)
* Aligning application interfaces with corporate brand visual standards
* Creating visual style guides (*Design System Guide*) for Front-End developers
* Ensuring display consistency across multiple screen sizes (*responsive design*)

### UX Researcher

* Conducting direct user interviews and usability testing
* Collecting and processing qualitative/quantitative data from user feedback
* Formulating empirical evidence-based product improvement recommendations
* Testing design hypotheses prior to full production deployment

## F. Infrastructure, DevOps & Deployment

### DevOps Engineer

* Setting up automated CI/CD Pipelines for testing, builds, and deployment
* Managing Infrastructure as Code (IaC) and workspace automation
* Monitoring system health, log aggregation, and incident recovery
* Enforcing operational gates prior to merging main code

### System Administrator & Cloud Engineer

* Managing server availability, cloud infrastructure, and production databases
* Monitoring system workloads, optimizing memory usage, and resource scaling
* Maintaining backups and Disaster Recovery planning
* Securing server networks, firewalls, and infrastructure account access

### Release Manager

* Planning release schedules and checking technical/legal compliance qualifications
* Verifying release decision logs in commit histories and repositories
* Controlling product release readiness for production environments or official app stores
* Drafting Release Notes and communicating changes to stakeholders
